IMDB Spark Project

Проєкт демонструє роботу з великими даними IMDb за допомогою Apache Spark (PySpark): від завантаження й обробки наборів даних до виконання бізнес-запитів і побудови базових моделей машинного навчання.
Мета — показати повний цикл ETL та просту аналітику на реальному датасеті. 📊

📁 Структура проєкту
```
main.py
modules/
    ├── extract.py      # Завантаження та схема датасетів
    ├── transform.py    # Бізнес-запити, join, window-функції
    └── analysis.py     # Навчання та оцінка ML-моделей
data/                   # Вхідні файли IMDb (.tsv)
output/                 # Збережені результати (.csv)
```
🔧 Основні етапи

1. Екстракція
Зчитування трьох офіційних датасетів IMDb:

title.basics

title.akas

title.ratings
Застосовано схеми та коректні типи даних.

2. Трансформація
Виконано 10 бізнес-запитів на Spark, включаючи:

фільтри, агрегування, groupBy

об'єднання таблиць

window-функції (rank, avg, over partition)
Результати експортуються у output/results.csv.

3. Моделі машинного навчання
Порівняно моделі:

LinearRegression

DecisionTreeRegressor

RandomForestRegressor

LogisticRegression

RandomForestClassifier

DecisionTreeClassifier

📌 Основні висновки

У датасеті IMDb понад 12 млн записів.

runtimeMinutes практично не залежить від року виходу (R² ~ 0).

Класифікаційні моделі показують точність понад 96%.

Для регресії дерева рішень працюють трохи краще за лінійну регресію.

Найстабільніший баланс precision/recall — у RandomForestClassifier.

🔍 Приклади бізнес-запитів

Кількість фільмів за жанрами — лідирують Drama та Comedy

Найбільше релізів у 2024–2025 рр.

Топ-10 найдовших фільмів — переважно експериментальні

Найбільша кількість фільмів 18+ — у 1960–1970-х

Короткометражок (<10 хв) — понад 0.5 млн

Документальні мають вищу середню тривалість

Join із рейтингами підтвердив коректність об'єднання

Рейтинг >6.0 добре збігається з відомими назвами

Window-функції: найдовший фільм у жанрі, середня тривалість по жанрах
