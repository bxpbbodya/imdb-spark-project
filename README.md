# 🎬 IMDB Spark Project

Аналітичний проєкт IMDb із використанням **Apache Spark (PySpark)**.  
Мета — продемонструвати етапи *ETL-процесу* (Extract, Transform, Load) та базові **моделі машинного навчання** на великому наборі даних.

---

## 📁 Структура проєкту

main.py
modules/
├── extract.py # Завантаження та схема датасетів
├── transform.py # Бізнес-запити, join, window, збереження
└── analysis.py # Побудова та оцінка ML-моделей
data/ # Вхідні дані IMDb (TSV)
output/ # CSV-результати та статистика

---

## ⚙️ Етапи виконання

1. **Екстракція** – зчитування трьох IMDb-датасетів (`basics`, `akas`, `ratings`)  
2. **Трансформація** – 10 бізнес-запитів (filter, join, groupBy, window)  
3. **Збереження результатів** – у `output/results.csv`  
4. **Аналіз (ML)** – побудова та порівняння моделей:
   - `LinearRegression`
   - `DecisionTreeRegressor`
   - `RandomForestRegressor`
   - `LogisticRegression`
   - `RandomForestClassifier`
   - `DecisionTreeClassifier`

## 🧠 Висновки

- IMDb-дані містять понад **12 млн записів**.  
- `runtimeMinutes` майже **не корелює з роком випуску** (R² ≈ 0).  
- Класифікаційні моделі дають **високу точність (>96%)**.  
- **DecisionTreeRegressor** показує трохи кращий R², ніж LinearRegression.  
- Для класифікації **RandomForestClassifier** забезпечує найкращий баланс між Precision і Recall.

## 💼 Бізнес-запити (аналіз)

| № | Запит | Висновок |
|---|-------|-----------|
| 1 | Кількість фільмів у кожному жанрі | Найбільше — *Drama*, *Comedy* |
| 2 | Кількість фільмів по роках | Пік у 2024–2025 роках |
| 3 | Топ-10 найдовших фільмів | Більшість експериментальні / артпроєкти |
| 4 | Фільми для дорослих | Найбільше у 1960–1970-х |
| 5 | Короткі фільми <10 хв | ~0.5 млн короткометражок |
| 6 | Середня тривалість за жанрами | Документальні — довші за середнє |
| 7 | Join із рейтингами | Перевірка правильності злиття |
| 8 | Фільми з рейтингом >6.0 | Збігаються з популярними назвами |
| 9 | Window – найдовший у жанрі | Тривалі документальні / експерименти |
| 10 | Window – середня тривалість | Показує різницю між жанрами |
